# 03 — Chat 1-1

## Mục đích
Nhắn tin riêng giữa hai người: gửi text/ảnh, typing, đã đọc, sửa/xoá, phân trang
lịch sử, gửi bù khi mất mạng.

## File chính
| File | Vai trò |
|---|---|
| `features/chat/chat_list_page.dart` | danh sách hội thoại + realtime |
| `features/chat/chat_detail_page.dart` | màn hình trò chuyện |
| `data/repositories/chat_repository.dart` | `chatProvider`, `messagesProvider`, `MessagesNotifier` |
| `core/network/outbox.dart` | hàng đợi tin nhắn chưa gửi được |
| `data/models/models.dart` | `ConversationModel`, `MessageModel` |

## Luồng gửi tin
```text
nhập tin → _send()
   ├─ ensureOnline() ─── mất mạng → đưa vào outbox, hiện "chờ gửi"
   ├─ POST /api/conversations/:id/messages
   │     └─ server lưu DB rồi emit chat:message cho cả hai bên
   └─ socket chat:message → MessagesNotifier thay tin optimistic bằng tin thật
```

- Tin optimistic có `clientMessageId`; khi server phát lại, notifier khớp
  `clientMessageId` để **không nhân đôi** tin.
- `chatProvider.applyIncoming` cập nhật "tin cuối" và thứ tự danh sách; hội thoại
  lạ (chưa có trong list) → tự `load()` lại danh sách.
- Outbox nạp lại từ đĩa khi mở app và `flush()` khi mạng trở lại.

## Realtime
| Sự kiện | Xử lý |
|---|---|
| `chat:message` | thêm tin, cập nhật danh sách chat |
| `chat:message-edited` | thay nội dung tin |
| `chat:message-deleted` | xoá tin khỏi UI |
| `chat:typing` | hiện "đang nhập…" 3 giây |
| `presence:changed` | chấm online/offline của bạn chat |
| `conversations:changed` | người khác vừa mở hội thoại với mình → tải lại danh sách |

## Phân trang
`GET /api/conversations/:id/messages?before=<ISO>&limit=50` trả `hasMore`. Kéo
lên đầu danh sách (ListView `reverse: true`) → `loadMore()`.

## Đã đọc
Mở hội thoại gọi `GET …/messages`, server đánh dấu `is_read = 1` cho tin của đối
phương; danh sách chat xoá badge chưa đọc bằng `copyWithUnread(0)`.

## Ghi chú
- Nội dung tối đa 2000 ký tự (server cắt và trả lỗi nếu rỗng).
- Ảnh: upload qua `/api/upload` trước, tin nhắn `type = 'image'`.
- Không có "xoá hội thoại" — lịch sử thuộc database.
